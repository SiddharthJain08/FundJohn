# Free (keyless) data streams

Keyless public feeds that land in `data/master/` via their own systemd timers.
Every writer here goes through `src/data/parquet_store.append_dedup`
(atomic tmp + `os.replace`, per-file lock) and obeys the CLAUDE.md core
invariant: masters are APPEND-ONLY — rows, tickers and columns may be added,
never dropped. All of them print COUNTERS on stdout and reserve `rc=1` for
"the provider could not be read at all"; read the counters in the log, not
the exit code.

Unit files live in `docs/systemd/` (byte-identical to `/etc/systemd/system/`);
logs append to `/var/log/openclaw-<name>.log`.

| Stream | Master | Key | Timer (America/New_York) | Script |
|---|---|---|---|---|
| FINRA biweekly short interest | `short_interest.parquet` | (settlement_date, ticker), replace | Mon–Fri 07:10 | `src/ingestion/ingest_finra_short_interest.py` |
| Nasdaq earnings calendar | `earnings_calendar_nasdaq.parquet` | (report_date, ticker), replace | Mon–Fri 06:40 | `src/ingestion/ingest_nasdaq_earnings_calendar.py` |
| CBOE | _(operator to add)_ | | | |
| Macro | _(operator to add)_ | | | |

## FINRA biweekly consolidated short interest

**Endpoint** (no key, no special headers; verified 2026-08-23):

    GET https://cdn.finra.org/equity/otcmarket/biweekly/shrt{YYYYMMDD}.csv

Pipe-delimited, ~22k rows / ~2.1 MB per settlement date. Header:

    accountingYearMonthNumber|symbolCode|issueName|issuerServicesGroupExchangeCode|
    marketClassCode|currentShortPositionQuantity|previousShortPositionQuantity|
    stockSplitFlag|averageDailyVolumeQuantity|daysToCoverQuantity|revisionFlag|
    changePercent|changePreviousNumber|settlementDate

**Cadence.** Settlement dates are the **15th and the last business day of each
month**, rolled BACK to the preceding business day when they fall on a
weekend/holiday. FINRA publishes **~9 business days after settlement** (on
2026-08-23 the 2026-07-31 file was live, 2026-08-14 was not).

**403 means "unpublished"** — the CDN answers 403 both for a date that is not a
settlement date and for a settlement date not yet published. The ingest logs
it at INFO (`files_unpublished`), never as an error. Candidate dates are
generated by rolling the 15th/month-end over weekends only; a candidate that
403s is retried on the 1–2 preceding business days (covers holidays such as
MLK day 2024-01-15 → 01-12, Good Friday 2024-03-29 → 03-28). Whatever URL
served the file, the CSV's own `settlementDate` column is what is stored.
Settlement dates already present in the master are skipped without a request
(`files_skipped`) unless `--force`.

**Schema** (`settlement_date` is `date32`; ints are `int64`, nullable):

| column | type | from |
|---|---|---|
| settlement_date | date | settlementDate (authoritative) |
| ticker | string | symbolCode, upper/strip |
| issue_name, exchange, market_class | string | issueName, issuerServicesGroupExchangeCode, marketClassCode |
| short_interest, prev_short_interest | int64 | current/previousShortPositionQuantity |
| avg_daily_volume | int64 | averageDailyVolumeQuantity |
| days_to_cover, change_pct | double | daysToCoverQuantity, changePercent |
| change_shares | int64 | changePreviousNumber |
| split_flag, revision_flag | string (null when blank) | stockSplitFlag, revisionFlag |
| source | string `'finra'` | |
| fetched_at | timestamp[us, UTC] | |

Key `(settlement_date, ticker)`, `mode='replace'` — FINRA re-publishes revised
files (`revisionFlag`), the newer row wins. ALL symbols in the file are kept.

**CLI.** `--backfill-from YYYY-MM-DD` (default today−45d), `--until` (default
today), `--force`. 0.5 s between requests. Counters:
`candidates files_fetched files_skipped files_unpublished files_error fetched
new_rows replaced_rows master_rows_after rc`. `rc=1` only when the first
request raised (network down) or EVERY candidate in the window failed with a
non-403 HTTP error.

**Backfill** (one-off, detached):

    systemd-run --unit openclaw-finra-si-backfill --nice=19 \
      --property=WorkingDirectory=/root/openclaw --setenv=PYTHONPATH=/root/openclaw/src \
      /usr/bin/python3 src/ingestion/ingest_finra_short_interest.py --backfill-from 2024-01-01

## Nasdaq earnings calendar (keyless)

**Purpose.** A same-day cross-check of report **timing** (pre-market /
after-hours) and consensus (`eps_forecast`, `num_estimates`) for the
pre-earnings strategies. The MASTER `earnings.parquet` is fed from FMP
`/stable/earnings-calendar` by `ingest_earnings_master.py`; this file is a
second, independent opinion and is **not** merged into `earnings.parquet`.

**Endpoint** (unofficial browser API; verified 2026-08-23):

    GET https://api.nasdaq.com/api/calendar/earnings?date=YYYY-MM-DD
    User-Agent: <browser UA>   Accept: application/json
    Origin: https://www.nasdaq.com   Referer: https://www.nasdaq.com/

JSON `{"data": {"rows": [{"lastYearRptDt": "8/26/2025", "lastYearEPS": "$2.33",
"time": "time-pre-market", "symbol": "BMO", "name": "Bank Of Montreal",
"marketCap": "$121,887,293,613", "fiscalQuarterEnding": "Jul/2026",
"epsForecast": "$2.72", "noOfEsts": "3"}, …]}}`. `time` values seen:
`time-pre-market`, `time-after-hours`, `time-not-supplied`.

**Brittleness.** Three browser UAs are rotated, 1 s between days. 403 / 429 /
non-JSON / empty JSON (`data` null or no `rows`) / request exceptions are
"day unavailable": counted in `days_failed`, non-fatal. A 200 with
`rows: []` is a real empty day (`days_ok`, 0 rows). `rc=1` only when ALL days
in the window failed.

**Schema** (`report_date`, `last_year_report_date` are `date32`):

| column | type | from |
|---|---|---|
| report_date | date | the `?date=` queried |
| ticker | string | symbol, upper/strip |
| company_name | string | name |
| report_time | string `pre` / `after` / `unknown` | time |
| eps_forecast, last_year_eps | double | epsForecast / lastYearEPS — `$`, `,` stripped; `$(0.12)` → −0.12; blank / `N/A` → null |
| num_estimates | int64 (nullable) | noOfEsts |
| last_year_report_date | date | lastYearRptDt (M/D/YYYY) |
| market_cap | double | marketCap |
| fiscal_quarter_ending | string as given | fiscalQuarterEnding |
| source | string `'nasdaq'` | |
| fetched_at | timestamp[us, UTC] | |

Key `(report_date, ticker)`, `mode='replace'` — timing/consensus changes
overwrite in place; rows are never dropped.

**CLI.** `--days-ahead` (default 45) and `--days-back` (default 3, catches
late changes), business days only (weekends skipped; holidays just return an
empty day); `--today YYYY-MM-DD` anchor for reruns. Counters:
`days days_ok days_failed rows new_rows replaced_rows master_rows_after rc`.
