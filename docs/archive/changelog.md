- **2026-07-16: effective_sharpe is BACKTEST-ONLY; live_sharpe recorded but never blended** (operator directive). `strategy_weights._effective_sharpe` was `(bt_n×bt_sharpe + live_n×live_sharpe)/(bt_n+live_n)`. Retired for two independent reasons. (1) **Attribution**: the book takes AGGREGATED positions — many strategies signal one ticker, the broker holds ONE position, and it exits through ONE Sharpe-weighted stacked bracket (`bracket_stacking.stacked_bracket`). If S1 wants stop −5%/target +3% and S2 wants −8%/+6%, the live exit fires at the blended level and BOTH are booked that shared outcome; **neither strategy's own rule ever ran**, so per-strategy live pnl_pct measures the blend, not the strategy. Measuring a strategy live would need a separate paper account where each fires its own brackets — we have none. (2) **Units**: `bt_sharpe` is an ANNUALIZED daily-return Sharpe (`(mean−rf)/std×√252`); `live_sharpe` is a RAW per-trade ratio (`mu/sigma` over pnl_pct) with no time basis — the blend averaged two different quantities. Concretely the blend let live data **rescue a failing backtest**: bt −0.40 + live 3.00 over 500 trades → **+2.81, sized**. Now `effective_sharpe = bt_sharpe`, and a **live-only strategy is NOT sizeable** (eff None) — deliberate; measured at the change, 0 of 70 current weight rows were live-only (69 bt-only, 1 blended with drag **0.00**), so this was inert-but-latent and deactivated nothing. `live_sharpe`/`live_n` are still computed and persisted for observability and a future **portfolio-level** Sharpe, which IS measurable because it needs no per-strategy attribution. **Takes effect at the next weights rebuild** (`weekly_live_sharpe.js`, weekend_saturday step 7). Tests: `tests/test_effective_sharpe_excludes_live.py`. **Dashboard was already clean** — `/api/strategies` reads `strategy_backtest_panel` (built from canonical `strategy_backtest_runs primary_window`) and touches no `signal_pnl`/`signal_performance`/`execution_signals`/`strategy_weights_by_regime`; only `last_signal_date` + `status` stay live.
